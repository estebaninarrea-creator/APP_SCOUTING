# Guía de Exportación a PDF

Fecha: 2026-07-27

## Objetivo

Dejar los manuales listos para entregar en formato PDF.

## Archivos de origen

- [Manual técnico](MANUAL_TECNICO.md)
- [Manual de usuario](MANUAL_USUARIO.md)

## Opción recomendada

1. Abrir cada archivo Markdown en VS Code.
2. Usar la vista previa o un conversor Markdown a PDF.
3. Exportar primero el manual técnico y luego el manual de usuario.
4. Guardar los PDFs con estos nombres:
   - `MANUAL_TECNICO.pdf`
   - `MANUAL_USUARIO.pdf`

## Opción alternativa

Si se prefiere una entrega simple dentro del repositorio:

1. Mantener los manuales en Markdown.
2. Compartir la carpeta `backend/docs` completa.
3. Indicar que el contenido está listo para impresión a PDF.

## Checklist final

- La portada está visible.
- El índice está visible.
- El contenido está separado por secciones.
- El manual de usuario tiene pasos claros por pantalla.
- El manual técnico describe arquitectura, permisos y ejecución.
